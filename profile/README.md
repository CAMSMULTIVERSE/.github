# CAMS — Cameron Andrews Multiversal Services

**CAMS** is an independent media and technology studio founded by **Cameron Andrews**. It brings together recording arts, creator media, and self-hosted infrastructure.

## What we're building
- **CAMS OS** (in development): a self-hosted entertainment and creator OS. It's a web dashboard and app platform on Ubuntu/Debian, with creator tools pre-wired: stream relay, chat bot, clip pipeline, media hub, and an approval queue. The plan is open-core and built only on permissively licensed components.
- **AI hub:** a self-hosted AI gateway and automation stack (LiteLLM + n8n + dashboard) for agent workflows. It runs on a private network, not the public internet.
- **$0 multi-cloud infrastructure:** free-tier cloud nodes (AWS, Oracle Cloud, Azure) joined into one private **Tailscale** network with no public ports, ACL-scoped access, and secrets kept out of source control.
- **Cyber lab:** an isolated, authorized security-training lab (OWASP Juice Shop, DVWA) on a private network for hands-on defensive and offensive practice. It only targets systems we own.
